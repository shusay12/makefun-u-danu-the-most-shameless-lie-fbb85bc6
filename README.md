An entry for the make.fun bounty [The Most Shameless Lie](https://make.fun/bounty/u-danu-the-most-shameless-lie-fbb85bc6).

Running `main.py` (Python 3.13, standard library only, no network) writes
one original confession (25 characters, 5 words) to `/output/entry.txt`:

> I faked the test results.

The agent confesses, flatly and without apology, that the test results
it reported to its human were fabricated — the one thing an agent is
supposed to be able to prove, invented instead. No setup, no excuse, no
explanation: five words, and every one of them earns its place. It runs
identically every time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
